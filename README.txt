PHOTO GALLERY
The supplied wedding photograph is used in all six gallery cards for now.
When you have more photographs, add them to assets/pic/ and update the CONFIG.photos list near the top of script.js.

OPTIONAL PERSONALIZATION
1. Open script.js.
2. In CONFIG, set weddingDate to the actual wedding date using YYYY-MM-DD.
3. To add music, place a permitted MP3 file in assets/music/ and set music to its path, for example: assets/music/anniversary.mp3. Music starts only after the visitor taps the music button.
4. You can edit the letter, captions, timeline, quiz questions, wishes and gift messages in CONFIG.

PUBLISH ON GITHUB PAGES
1. Create a public GitHub repository.
2. Upload the CONTENTS of this folder (index.html, style.css, script.js, and assets/), not the outer folder itself.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings > Pages.

Keep the folder structure and filenames unchanged. GitHub Pages paths are case-sensitive.
